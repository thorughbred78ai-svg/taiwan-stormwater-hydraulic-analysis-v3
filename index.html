台灣雨水下水道數值水理分析 V3

本系統 V3 已由單純展示介面推進為 「節點／管段網路數值水理分析」架構。 水理計算核心、HGL/EGL 成果分析及工程檢核分離， 便於後續依工程案件調整檢核參數。

目前計算功能

① 網路拓撲

節點、管段、上游節點、下游節點及匯流關係。

② 節點連續方程

以節點流量平衡建立雨水下水道網路求解。

③ Manning 非滿流

圓形管渠依水深計算面積、濕周、水力半徑及流速。

④ 滿管切換

當水深達管徑時進入滿管／壓力流判斷邏輯。

⑤ HGL / EGL

由水深、管底、速度水頭及能量損失建立水力坡線。

⑥ 下游回水

由下游控制水位沿管網反算上游能量線及水力坡線。

計算架構

Input Nodes / Pipes ↓ Hydraulic Network Solver ↓ Node Continuity ↓ Manning Partial Flow ↓ Full-Pipe / Pressure Transition ↓ window.v3HydraulicSolution ↓ HGL / EGL Engine ↓ Friction Loss + Local Loss ↓ Downstream Boundary / Backwater ↓ window.v3HglEglSolution ↓ Engineering Checking ↓ Profile / CSV / Excel

規範依據與使用原則

本系統將「水理計算」與「工程檢核參數」分離。 例如計畫下水量時的流速檢核值，不應直接寫死於 hydraulic.js，而由 checking.js 的工程檢核設定管理。
工程使用注意： 本系統為數值水理分析工具。正式工程設計仍應依案件條件、 最新法規、設計指南、地形測量、管網調查、邊界條件及 技師專業判斷進行確認。
